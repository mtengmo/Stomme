# Browse and build a workout

The exercise library shows a static SVG thumbnail for each exercise. A tap plays one preview at a time; leaving the viewport stops it. Reduced motion remains still. The Granska route uses the same animation and pause control as the full guide, without frame-selection controls.

Choose up to 12 exercises across filters, in selection order. The selection survives guide visits and reloads in the current browser tab. Save a name under Mina egna pass, then open it to adjust exercises, sides, sets, repetitions or duration, total weight and rest. Save changes to reuse that dose, or start directly. Up to 30 named workouts are stored in IndexedDB and included in JSON backup/restore. Deleting a workout preserves recorded sessions and their name snapshots.

Custom workouts retain the current training direction, equipment checks, readiness and symptom questions. Knee rehabilitation still restricts the exercise selection to the AAOS collection; change training direction for a general workout. The default A/B workouts remain available.
